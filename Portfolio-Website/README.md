# Akuma Portfolio

Cybersecurity-focused portfolio and personal brand website for a software engineer, ethical hacker, and pentester 🛡️💻🔐.

This project presents a neon cyber aesthetic, interactive terminal-style interface, and a clean profile layout to showcase skills, projects, and contact links in a bold digital identity.

## Features

- Cyber-inspired UI with neon effects and dark hacker theme
- Custom terminal-style profile section
- Social links and contact entry points
- About section with personal branding
- Project archive area for future work
- Responsive single-page design

## Tech Stack

- HTML
- CSS
- JavaScript
- Chart.js (for visual graph sections)

## Run Locally

From the project folder, start a local web server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
